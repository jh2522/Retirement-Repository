ABOUT THIS TOOL

Retirement planning should feel understandable.

This website turns everyday financial choices into clear, year-by-year retirement projections you can explore for yourself.

This project began as an Excel retirement calculator. The website keeps the same practical goal: help people see how saving, investing, spending, inflation, and passive income can work together over time.

It is designed for learning and scenario planning. Change an input, compare the result, and build a better understanding of which choices have the greatest effect on your retirement.

How the projections work

Clear timing

Balances are shown at the start of each age. This keeps the chart, tables, retirement-age results, and Life Expectancy results on the same timeline.

Today's spending power

Retirement spending is entered in today's dollars, then increased for inflation so future expenses reflect the lifestyle entered today.

Visible assumptions

The model uses the return, inflation, income growth, and passive-income values you choose. Testing more cautious and more optimistic inputs can show a range of possible outcomes.

For the detailed calculation rules, open What result is the calculator showing? or What result is the calculator targeting? at the bottom of each calculator.

What this calculator does not do

This is an educational planning tool—not a guarantee, financial plan, or recommendation. It uses constant average returns and does not currently model taxes, fees, changing market returns, account-specific rules, healthcare costs, or every detail of Social Security and pensions.

Real outcomes can be very different. Consider testing several scenarios and consulting a qualified professional when making important financial decisions.

Privacy and feedback

The calculator performs its calculations in your browser. This version does not include accounts and does not save the financial values you enter.

This tool is still growing. A dedicated way to send questions and feedback will be added before the public launch.
